- **LEG-01 — P2/P3, confirmed unsafe data flow; remote exploit not established:** P1 echoes the command field as HTML. [public/old/projects/p1/js/Controller.js:93](/Users/ncteisen/git/website/public/old/projects/p1/js/Controller.js:93) passes `"> " + resp` to `add_paragraph_simple`, and [public/old/projects/p1/js/p1_main.js:36-37](/Users/ncteisen/git/website/public/old/projects/p1/js/p1_main.js:36) sends it to jQuery `.append("<p>" + text)`. A local Node VM fixture proves a typed `<b data-audit="fixture">…</b>` reaches that sink unchanged. This allows user-entered markup rather than literal command text; active HTML is a self-XSS risk. I did not demonstrate browser script execution or find a URL/storage/message path that delivers attacker input to another visitor, so do not label this a proven remote XSS vulnerability. **Action:** build a paragraph element and set `textContent` for echoed commands; keep authored narrative formatting in a separate trusted-rendering path. Test that tags, event attributes, and `<script>` text remain text. Rank P2 if legacy game remains supported; otherwise P3 archive cleanup.

- **LEG-02 — P3, runtime reproduced:** P1's apparent restart does not reset puzzles or completion state. [public/old/projects/p1/js/Room4.js:14,17-21](/Users/ncteisen/git/website/public/old/projects/p1/js/Room4.js:14) sets its state to 0 after victory, then only assigns `controller.room = 1`; room instances are created just once at `Controller.js:7-10`. A local full solve/restart fixture left Room2's key and Room3's solved flag true. The second loop skips those puzzles, and Room4 never emits a second victory message because its state remains 0. **Action:** add an explicit restart/reset that recreates all rooms and resets terminal state, or make the ending terminal with a reload/restart action. Validate two complete games in the same page session.

- **LEG-03 — P2/P3 maintenance risk, no actual library exploit claimed:** Archived pages still execute CDN jQuery 1.11.1 ([public/old/projects/p1/index.html:37](/Users/ncteisen/git/website/public/old/projects/p1/index.html:37), similarly legacy root/stories/notes/projects) and local Bootstrap 3.2.0 ([public/old/js/bootstrap.min.js:2](/Users/ncteisen/git/website/public/old/js/bootstrap.min.js:2)). These scripts are outside package.json/lockfile dependency accounting, so a clean npm audit does not assess them. The [official jQuery 3.5.0 release notes](https://blog.jquery.com/2020/04/10/jquery-3-5-0-released/) document security fixes in HTML handling that postdate this version. The legacy archive is served on the site's origin; `/old/` is not a browser security boundary. **Action:** include vendored/CDN assets in dependency inventory, remove unused Bootstrap/jQuery behavior where simple native code suffices, or refresh/isolate the executable archive. Test navigation and P1 gameplay after changes. Inventory is confirmed; reachability of a specific dependency CVE through this app was not tested.
